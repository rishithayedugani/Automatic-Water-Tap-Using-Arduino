# Automatic-Water-Tap-Using-Arduino
Automatic touchless water tap using Arduino and IR sensor.
## Project Description
A touchless water tap system that detects hand presence and controls water flow automatically.

## Technologies Used
- Arduino Uno
- IR Sensor
- Relay Module

## Features
- Touchless operation
- Reduces water wastage
- Automatic water control
